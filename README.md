# quickchart

コンサルティング資料でよく使われる図解パターン(マトリクス、ピラミッド、ロジックツリー、ベン図など)を、効率よく作図するためのWindows向けデスクトップアプリケーション。

汎用の図形エディタ(矩形・楕円・線・矢印・コネクタ・テキスト)を土台としつつ、頻出パターンは階層テキストからワンクリックで自動レイアウト生成できる。生成後はキャンバス上の通常図形として自由に編集できる。

設計の背景・詳細は [`doc/requirement.md`](doc/requirement.md)(要求仕様)・[`doc/spec.md`](doc/spec.md)(設計)・[`doc/plan.md`](doc/plan.md)(実装計画)を参照。

## 動作環境

- Windows のみ(PowerPoint貼り付け対応がWindows固有のEMFフォーマットに依存するため)
- [Node.js](https://nodejs.org/)・[Rust](https://www.rust-lang.org/tools/install) が必要

## セットアップ

```powershell
npm install
```

## 開発

```powershell
npm run tauri dev
```

デスクトップアプリとして起動する。フロントエンドのみを素早く確認したい場合は `npm run dev` でVite開発サーバーを起動できるが、その場合はRustコマンド(保存/読込・エクスポート・ユーザーテンプレート)は動作しない。

## テスト・型チェック

```powershell
npm run test          # フロントエンドの単体テスト(Vitest)
npx tsc --noEmit       # 型チェック
cd src-tauri; cargo test  # バックエンドの単体テスト
```

## ビルド

```powershell
npm run build          # フロントエンドのビルド(バージョン同期を含む)
npm run tauri build    # 配布用インストーラの生成
```

`src-tauri/tauri.conf.json` の `version` が唯一の真実源。`npm run build` 実行時に `package.json`・`src-tauri/Cargo.toml` へ自動反映される(`scripts/sync-version.mjs`)。

## 基本的な使い方

### 1. 自由配置での作図

左パネルのツール(四角形・楕円・直線・テキスト・コネクタ・矢印)を選んでキャンバスをクリックすると図形が配置される。配置後は選択してドラッグで移動、ハンドルでリサイズ・回転できる。ドラッグ中はグリッドに吸着するほか、他の図形の端・中心と揃う位置に近づくと青いガイド線が表示されてその位置に吸着する。テキスト図形はダブルクリック(またはPropertyPanelの「内容を編集」ボタン)で内容を編集できる。

コネクタ・矢印は、始点を図形上でクリックしてドラッグし、終点を別の図形上または空白でリリースすると作成される。図形に接続したコネクタは、その図形を動かすと追従する。

右パネル(プロパティ)で位置・サイズ・色・線種・フォントなどを調整できる。四角形は「角丸」の値を指定すると角丸矩形になる。複数選択時は整列・分布・グループ化も可能。

`Ctrl+C`/`Ctrl+V` でコピー&ペースト、`Ctrl+D` で複製できる。別のタブへの貼り付けも可能。構造化テンプレートから生成した図形を貼り付けた場合は、階層テキストと同期しない通常の図形になる。

### 2. 構造化テンプレート

対応パターン: ツリー図、ロジックツリー図、４象限マトリクス、N×Nマトリクス、ベン図、見出し付き箇条書き、箇条書きマトリクス、ピラミッド図、ビフォーアフター(縦/横)、およびスケジュール系(ガントチャート、フロー図(縦型/横型)、フロースケジュール(縦/横)、タイムライン、フローチャート。ライブラリでは「スケジュール」のサブメニューにまとまっている)、サイクル図(円のみ/導入部あり。ライブラリでは「サイクル図」のサブメニュー)。

1. 左パネルの「パターンライブラリ」からパターンを選択(空のブロックが作成される)
2. 表示される「階層テキスト」パネルで項目を入力。Tab/Shift+Tabで字下げ・字上げ、Enterで兄弟項目を追加
3. 入力に応じて自動でレイアウトが生成される

生成された図形をキャンバス上で選択すると、対応する階層テキストパネルに自動的に切り替わる。テキストはアウトライン側・図形側どちらを編集しても双方向に同期する(位置・サイズ・色などの見た目は同期されない)。ただし、ツリー図・ロジックツリー図以外のパターンで項目を追加・削除・並べ替えした場合や、テキストを一括インポートした場合は全体が再レイアウトされ、手動で調整した配置は元に戻る(Undoで取り消せる)。

マトリクスは4象限固定、ベン図は2〜3集合まで対応。ベン図は同じ文言の要素を複数集合に記載すると、重なり領域の図形として自動的にまとめられる。

### 3. ユーザーテンプレート

よく使う図形の組み合わせは、選択した状態で右パネルから名前を付けて登録できる。プロジェクトを跨いで再利用可能(アプリ設定ディレクトリに保存される)。左パネルの「マイテンプレート」から選んでキャンバスをクリックすると配置される。

### 4. 複数タブでの編集・プロジェクトの保存・読込

ツールバー下のタブバーから、1つのプロジェクトファイル内に複数の独立した図(タブ)を作成・切り替えできる。「+」でタブを追加、タブ名をダブルクリックで変更、ドラッグで並べ替え、×で閉じる(最後の1枚は閉じられない)。図形を含むタブを閉じるときは確認が表示される(閉じたタブは元に戻せない)。`Ctrl+T`(タブ追加)・`Ctrl+Tab`/`Ctrl+Shift+Tab`(次/前のタブへ切替)・`Ctrl+W`(閉じる)のショートカットにも対応。

上部ツールバーから新規作成・開く・保存・名前を付けて保存ができる。独自形式(`.qct`、JSON)がマスターファイルで、ファイル内の全タブがまとめて保存・復元される(タブ単位の保存はない)。直近使用ファイル一覧からも再度開ける。編集中のファイルに未保存の変更がある状態で別のファイルを新規作成・開こうとした場合や、アプリを終了しようとした場合は、「保存する」「保存しない」「キャンセル」の確認が表示される。

### 5. エクスポート

上部ツールバーの「エクスポート」から、表示中のタブの図をSVG・PNG・EMF(ファイル/クリップボード)に書き出せる(複数タブの一括書き出しはない)。EMFはPowerPointに貼り付けると図形として編集できる(ただし「グループ化解除」した際に、テキストの左/中央/右揃えがPowerPoint側の変換仕様により左揃えに正規化される既知の制限がある。詳細は `doc/spec.md` §8.3)。
